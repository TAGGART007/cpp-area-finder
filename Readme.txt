# AreaFinder

AreaFinder is a simple C++ console application that calculates the areas of different geometric shapes. The program demonstrates the use of functions, file inclusion, and basic inputoutput in C++.

## Features

- Square  
  Calculates the area of a square based on user input of side length.

- Circle  
  Calculates the area of a circle based on user input of the radius.

- Triangle  
  Calculates the area of a triangle based on user input of base and height.

- Rectangle  
  Calculates the area of a rectangle based on user input of length and width.

## Prerequisites

- C++ compiler (e.g., GCC, MinGW, or Visual Studio)
- Basic knowledge of running console programs

## How to Run

1. Make sure you have both `main.cpp` and `area.cpp` in the same folder.
2. Open the terminal or command prompt.
3. Compile the program

g++ main.cpp area.cpp -o AreaFinder
